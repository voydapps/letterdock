# Security policy

## How to report a problem

Please report security problems in private. Do not open a public issue.

1. Open [Report a vulnerability](https://github.com/voydapps/letterdock/security/advisories/new) in the Security tab of this repository.
2. Say what you found and how to repeat it.
3. Do not include passwords or private email text.

I will read it and answer as soon as I can.

## Supported versions

Only the newest release gets fixes. Please update to the latest version first:
https://github.com/voydapps/letterdock/releases/latest
